    2Import your iTunes XMLChoose a file

    The XML supplies the letter casing you want to display.

    1. Open iTunes.
    2. Choose File → Library → Export Library… and save the XML file.
    3. Select that file below, then choose Compare libraries.

    If caching is incomplete, comparison includes only names cached so far. Compare again after caching finishes to include the rest.
