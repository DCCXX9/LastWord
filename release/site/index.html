A few minutes to get started

Install the beta

  1. Download the ZIP and extract it into a folder you will keep.
  2. Open chrome://extensions and turn on Developer mode.
  3. Choose Load unpacked, then select the extracted folder containing manifest.json.
  4. In the settings page, enter your Last.fm username and select Connect profile. Refresh your Last.fm Library.
  5. Import your iTunes XML or open Display names to manage your preferences.

Already using an unpacked copy? Export JSON first. Update your existing folder, click Reload, then refresh Last.fm. Do not uninstall your working copy. A separate folder or store installation may have separate storage.

Know what you’re trying

Beta notes

Personal covers and native editing are included for testing. New covers can take time to resolve; cached selections are reused. Last.fm layout changes or missing album artwork may prevent a result. Native editing requires Last.fm editing access.

Automatic album-less scrobble correction is unavailable in this beta. Existing rule and discovery records are preserved for review. The extension does not run corrections while you listen.

Preferences stay in this browser installation. No analytics or developer server. Read the privacy policy and the extension’s Help page for details, backup and troubleshooting.
